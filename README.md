# open-avatar-kit

An open toolkit that takes an independent artist's 3D character from model to stage — submission specs, rig and export checklists, Unreal import notes, and a 3D-video shot list.

It's a new project, in active development. This is the open version of a pipeline already in weekly use — built free, for independent artists who don't have a studio's character pipeline behind them.

## Why this exists

Big studios have character pipelines and independent artists don't. An artist with a model and a deadline has no documented path from file to stage, and the work that exists is locked inside studios or paid courses. This kit is that path, free and open.

## What's in the kit

- **Submission specs** — what to deliver, in what form, so a character is stage-ready
- **Rig and export checklists** — the checks to run before a character leaves the artist's hands
- **Unreal import notes** — getting the character into Unreal and working on stage
- **3D-video shot list** — planning the shots a 3D character needs for video

## Built from a real rollout

Everything in the kit was learned getting real artists stage-ready: the 3D characters for four R.I.P Labels artists — **WPNX, W.I.T.S, ANGEASEUS, and KLONE** — coordinated through DNAsplit for the NEO ULTRA live shows.

## Who it's for

Every independent artist who wants a 3D presence and can't hire a studio to build it.

## Status

New project, in active development — no download numbers or dependents yet. The goal is a complete, working kit any independent artist can pick up and use, not just documentation for one roster.
